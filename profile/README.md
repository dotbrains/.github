## About Us

We build tools that make developers' lives easier — developer-environment automation, AI
coding-agent tooling, and the small sharp command-line tools we reach for every day. We care
about software that is ethical, user-centric, and a genuine pleasure to use.

A few principles guide everything we ship:

- **Simplicity** — intuitive tools that cut complexity and save time.
- **Efficiency** — automate the repetitive so humans do the interesting work.
- **Ethical software** — protect user data and privacy by default.
- **Community** — build in the open, for developers, with developers.

## ⚡ CLIs & tools

Small, focused command-line tools.

- [**configsync**](https://github.com/dotbrains/configsync) — sync macOS app settings across machines.
- [**gh-identity**](https://github.com/dotbrains/gh-identity) · [**awsw**](https://github.com/dotbrains/awsw) — per-directory GitHub identities and fast AWS/EKS context switching.
- [**glimpse**](https://github.com/dotbrains/glimpse) · [**yeet**](https://github.com/dotbrains/yeet) — a browser-based git diff viewer and a terminal macOS app uninstaller.
- [**fugue**](https://github.com/dotbrains/fugue) · [**prr**](https://github.com/dotbrains/prr) — a ghost mode for you AI coding agents, and run AI code reviews on your PRs.
